# Eco-Cultural Heritage App

Уеб приложение за търсене на еко-културно наследство в колекциите на
[Europeana](https://www.europeana.eu/), с карта на обектите и локализация.

Академичен проект. **Версия 0** (начален работещ прототип).

## Какво прави
- Търсене в Europeana по ключова дума, със заглавия на български или английски
- Филтър „само еко теми“
- Карта с обекти около потребителя (геолокация) и в избрана област от Европа
- Групиране на близки маркери
- Интерфейс на български и английски

## Технологии
- Бекенд: Python, FastAPI, httpx
- Фронтенд: TypeScript, Vite, Leaflet
- Данни: Europeana Search API

## Стартиране локално

### 1. Бекенд
cd server
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Копирай `.env.example` като `.env` и сложи своя Europeana API ключ.
uvicorn app.main:app --reload --port 3001

### 2. Фронтенд (във втори терминал)
cd client
npm install
npm run dev

Приложението е на http://localhost:5173

## Известни ограничения
- Само част от записите в Europeana имат географски координати.
- Много записи от един и същ град имат еднакви координати.
- Еко филтърът е базов, по ключови думи.

## Източник на данните
Данните идват от Europeana. Всеки запис има собствен лиценз и институция-
доставчик, които трябва да се посочват при преизползване.
